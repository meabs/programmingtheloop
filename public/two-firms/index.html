Two firms, one model

Two rival subscription businesses start level and face the same market for 36 months. One is organised around AI; one is a traditional team. Change the AI-native firm's assumptions below and see how often it ends up with more cash.

This page loads its simulator as an ES module, which browsers block on file://. Serve the folder instead, e.g. python3 -m http.server inside web/, then open localhost:8000.

This is a model, not a forecast. Every coefficient is invented for illustration. The numbers describe how the simulator behaves, not how real companies perform. What is worth taking away is which assumptions the answer is sensitive to.

Things worth trying

  • Drag defect factor from 1.0 to 1.7 and watch the win rate collapse. It is the steepest lever in the model.
  • Set decision cadence to 6 months. Almost nothing happens: the "agility" advantage is barely modelled.
  • Raise capacity and watch incidents climb: more output means more technical debt.
  • Switch to the ai-friction scenario to see how fast a bundle of small penalties compounds.

Runs entirely in your browser. The JavaScript simulator is a port of the Python one and is checked against it on tens of thousands of fixed-seed comparisons, including the random number stream. Win rate means "AI-native finishes with more cash than traditional", with a 95% interval from the number of runs; it ignores the size of the gap, which the tiles and histogram show.
