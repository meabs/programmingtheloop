# Learn

The first edition is the starting point for a living technical resource. These lessons reorganise its eleven chapters into shorter web reading while preserving its evidence and limits. The [original PDF](/downloads/) remains the permanent edition.

## Learning paths

| Path | Chapters | Focus |
| --- | --- | --- |
| Agent foundations | 1–2 | What an agent does; facts, checks, briefs and plans |
| Context and knowledge | 3 | Useful facts, missing dependencies, stale knowledge and repository guidance |
| Verification and harness | 4–6 | Small changes, proof, feedback and friction |
| Scaling and measuring | 7–11 | Parallel work, review, tools, cost, safety and the take-home kit |
