# Getting started

From the foreword: if you have twenty minutes, read Chapter 3 and Chapter 5, then the take-home kit in Chapter 11. If you are about to give an agent production credentials, read Chapter 10 first.

Findings are measured results with stated limits. Recommendations are engineering judgement. Where a recommendation goes beyond what I measured, the book says so.

1. [Chapter 3 — The right facts, not every fact](/learn/right-facts/) — the main evidence chapter
2. [Chapter 5 — Proof, not promises](/learn/proof-not-promises/) — executable checks, two comparisons
3. [Chapter 11 — The take-home kit](/learn/take-home-kit/) — what to adopt, and in what order

The free PDF is the permanent first edition: [Download Programming-the-Loop-1st-edition.pdf](/downloads/Programming-the-Loop-1st-edition.pdf).

If a number or limit looks wrong, [open an issue](https://github.com/meabs/ProgrammingTheLoop-WorkedExample/issues/new/choose) on the worked example.
