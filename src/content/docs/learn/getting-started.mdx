# Getting started

The foreword’s suggestion: if you have twenty minutes, read Chapter 3 and Chapter 5, then the take-home kit in Chapter 11. If you are about to give an agent production credentials, read Chapter 10 first.

## How to read findings

Each measured result describes a particular repository, model, task and run count. Those details constrain what can be concluded. A **finding** is a direct observation; a **recommendation** combines observations with engineering judgement; an **open question** remains untested.
