Start with the question closest to your work: what context to give an agent, how to verify its changes, or how to run repeatable trials. The [learning map](/learn/) groups the book’s eleven chapters around those decisions.

## Read findings with their conditions

Each measured result describes a particular repository, model, task and run count. Those details constrain what can be concluded. A result is a direct observation; a recommendation combines observations with engineering judgement; an open question remains untested.

## Suggested first pass

Read [Chapter 1](/learn/facts-checks-upkeep/) for the vocabulary and [Chapter 3](/learn/right-facts/) for the book’s central evidence. Then read [Chapter 5](/learn/proof-not-promises/) on verification. These are the author’s suggested priority chapters from the first edition.
