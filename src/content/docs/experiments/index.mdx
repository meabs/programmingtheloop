## Published findings from the first edition

<div class="experiment-evidence">
  <span class="experiment-status published">● &nbsp; MEASURED FINDING · EXPERIMENT J</span>
  <p><strong>Repository optimisation.</strong> A prepared copy of a 1,173-file Java repository used 35–48% more tokens. It scored 29 versus 28 of 32 changes and 19 versus 16 of 24 structure questions; both differences were described as within noise.</p>
  <div class="limitation"><strong>Limits</strong> One repository and model; mechanical edits and structure questions; 8 runs per task per arm; four repository ingredients were tested together. This does not show which ingredient mattered or establish what happens in other repositories.</div>

## Interpreting the results

- **Measured finding** means a direct observation from a named experiment, under the stated conditions.
- **Engineering recommendation** means advice informed by the findings and judgement. It is not itself a measured result.
- **Open question** means the evidence does not yet establish the answer.

See the [research methodology](/about/methodology/) for how to read sample sizes, repeated trials, evidence quality and limits. Source paths cited in the book are linked only where the corresponding public repository or file is available.
