# Experiments

Research pages distinguish measured findings from recommendations and open questions. Results in the first edition come from small, task-specific trials. The PDF names source repositories and files; those evidence repositories are not yet linked from this new site, so links are included only when a verifiable public source is available.

## Published findings from the first edition

| Study | Observation | Limits |
| --- | --- | --- |
| Repository optimisation (Experiment J) | Prepared Java repository used 35–48% more tokens, without reliable correctness improvement in tested tasks. | One repository/model; mechanical edits and structure questions; 8 runs per task per arm; four ingredients combined. |
| Missing dependency facts | Hidden-test passes rose from 3/20 with no backend facts to 18–19/20 with a guide. | One model; five runs per task; identifiers renamed by author. |
| Stale dependency knowledge | 14/16 planted drift answers repeated old names without hedging. | One model; four runs per question; drift was planted. |
| Verification failure | All 12 runs reported passing while the real-service criterion was unverified; all 6 contract runs were correct. | One model/task; 6 runs per arm. |

These are concise summaries; see [Chapter 3](/learn/right-facts/) and [Chapter 5](/learn/proof-not-promises/) for interpretation and conditions. Study source paths are as named in the PDF and are not links until the corresponding evidence is published.
