# About

Programming the Loop is an independent engineering research and learning website about coding agents, harness engineering, repository design, context management, verification and controlled experimentation.

The first edition is by Garry Meaburn, an infrastructure and cloud architect. The ebook describes more than 25 years of work and roles including Senior Solutions Architect at AWS, with earlier positions at Barclays, Rathbones, Gartner, Unilever and Microsoft. Views are the author’s own and do not represent any employer.

The website’s purpose is to help engineers separate direct observations from recommendations and open questions. It is not a commercial SaaS product.
