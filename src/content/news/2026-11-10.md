    title: "Claude Fable 5.2 and Mythos 5.2"
    releasedOn: "9 Nov 2026"
    body: |
      Fable 5.2 (`claude-fable-5-2`) is generally available on the Claude API, Bedrock, Google Cloud, Microsoft Foundry and Claude Platform on AWS. It has a 1M token context window and 128K maximum output, and costs $8/$40 per million tokens, which is cheaper than 5.1. Output is up to 30% faster, and an optional fast mode costs $16/$80.

      Mythos 5.2 is the same model without the cyber and bio safeguards. It is limited to organisations verified through Anthropic's Cyber and Life Sciences programmes.

      The release is aimed at long-horizon agent runs. It comes with breaking changes: thinking blocks are only readable by Fable or Mythos 5.2, the older `computer_20251124` tool errors outside Bedrock, a Fable 5.2 executor needs a 5.2 advisor, and the model needs 30-day data retention, so zero data retention is not on by default. The [Fable 5.2 docs](https://platform.claude.com/docs/en/models/fable-5-2/whats-new-fable-5-2) list the details.
    whoItAffects: "Teams running long agent workflows on Claude. Before switching, check the breaking changes, especially the computer use tool version, executor and advisor pairing, and whether 30-day data retention fits your data policy."
    sourceUrl: "https://www.anthropic.com/claude-fable-and-mythos-5-2"

  - vendor: "Anthropic"
    title: "Claude Code 2.1.321 and 2.1.322"
    releasedOn: "9 and 10 Nov 2026"
    body: |
      2.1.321 makes Fable 5.2 the default Fable model and adds `--settings <file>` for `claude remote-control`. It also includes security fixes: MCP OAuth could send refresh tokens to another host after a redirect, and some Bash commands and `cp`/`mv` writes skipped sandbox or deny-rule checks.

      2.1.322 adds fast mode on Vertex (global, us, eu), falling back to standard speed if the request is refused.
    whoItAffects: "Claude Code users with MCP OAuth servers or who rely on permission rules should update soon."
