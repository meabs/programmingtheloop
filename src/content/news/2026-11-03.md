    body: |
      Web and shell tools now ask before sending your account email anywhere, and Agent SDK hooks can set `onFailure: "block"` so a failed hook stops the action instead of letting it through.

      The Claude apps gateway adds admin cost analytics at `GET /v1/organizations/analytics/cost` (totals, per developer, per day and per IdP group), IdP group retention, and new OpenTelemetry attributes for plan, seat type, provider and custom base URL.

      There is also a `/schedule` connector warning, a new `CLAUDE_CODE_DISABLE_NESTED_SESSION_ID` setting, and a batch of fixes covering MCP disconnects, auto-mode 403 and 422 errors behind gateways, auth refresh, `--from-pr`, Remote Control, self-hosted runner recovery, Windows path checks and OpenTelemetry proxy timeouts.
    whoItAffects: "Teams wiring Claude Code into an enterprise setup. Check the new cost analytics endpoint, fail-closed hooks, and the email-send prompt if you rely on web or shell tools."

  - vendor: "Anthropic"
    title: "Messages API message threads, beta"
    releasedOn: "2 Nov 2026"
    body: |
      Long conversations and agent loops can keep their conversation state on Anthropic's servers, so later turns only send the new messages. That means smaller payloads and a faster first token.

      You opt in with the beta header `message-threads-2026-08-12`. Threads expire five minutes after the last request and are deleted within an hour of last use. It is available on the Claude API, Claude Platform on AWS, Claude Models on Google Cloud (Anthropic managed) and Claude in Microsoft Foundry.
    whoItAffects: "Anyone running multi-turn coding agents that currently resend the whole history every turn. Worth checking if the latency and payload savings fit your loop, and that five-minute expiry works for your session length."
    sourceUrl: "https://docs.claude.com/en/release-notes/overview"
    sourceLabel: "Claude release notes"
  - vendor: "Google"
    title: "Gemini 2.5 Pro and 2.5 Flash deprecated"
    releasedOn: "2 Nov 2026"
    body: |
      Both models are deprecated and gone from the AI Studio model picker. From 1 December 2026, `gemini-2.5-pro` requests will be routed to `gemini-3.8-flash` and billed at 3.8 Flash rates, and `gemini-2.5-flash` requests will go to `gemini-3.5-flash-lite` at Lite rates.

      The breaking changes include stricter function-calling and `thought_signature` validation, `thinking_level` replacing `thinking_budget`, and the removal of some sampling parameters and prefilled model turns.
    whoItAffects: "Anyone still pinned to a 2.5 model name. Migrate before 1 December 2026 or you get a silent model swap, a different bill and possible schema errors."
    sourceUrl: "https://ai.google.dev/gemini-api/docs/changelog"
    sourceLabel: "Gemini API release notes"
