      Each new SDK uses the new API version by default: Python 2.0.0, TypeScript 1.0.0, Go 2.0.0, Java 3.0.0, C# 13.0.0, PHP 1.0.0, Ruby 2.0.0, and the `ant` command-line tool 2.0.0.

  - vendor: "Anthropic"
    title: "Claude Code 2.1.307"
    releasedOn: "21 Oct 2026, 23:17 UK"
    body: |
      `/claude-api api-version` updates your Claude API code to the new `2026-10-21` version.

      A new OpenTelemetry event, `claude_code.safety_event`, is recorded whenever a permission rule, auto mode, a safety check, a hook or the sandbox blocks, asks about or sends back a tool call.

      If a connection drops partway through a call to an MCP server over HTTP, the call is no longer sent twice. Only read-only or idempotent tools are retried now.

      Checkout hooks on self-hosted runners now time out after 30 minutes by default, which you can change with `--checkout-hook-timeout-min`. `@claude review stop` cancels an always-on Code Review subscription.

      Versions 2.1.306 and 2.1.308 were bug fixes only.
    whoItAffects: "Teams that want an audit trail of when agent guardrails stepped in, and anyone using HTTP MCP tools that change things, which no longer risk running twice."
    sourceUrl: "https://github.com/anthropics/claude-code/releases/tag/v2.1.307"
    sourceLabel: "Claude Code 2.1.307 release notes"
