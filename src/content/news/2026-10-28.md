  - vendor: "Google"
    title: "Gemini API CLI, beta"
    releasedOn: "27 Oct 2026"
    body: |
      `gemini-api`, previously an experimental preview, has moved to beta. It's an open-source, zero-dependency command-line client built for coding agents, scripts and CI rather than for people typing at it.

      It runs on the Interactions API and covers text, images, speech, music and video generation, file analysis and transcription, and launching managed agents such as Deep Research in the background. Media is written to disk with only the path printed, commands never prompt unless you ask, `--dry-run` previews a request offline, and exit codes are typed (2 for bad usage, 3 for auth).

      Google warns that breaking changes can land between minor versions. Separately, A2UI (Google's generative UI format) gets A2UI Express, a compact syntax Google says uses up to 3x fewer tokens.
    whoItAffects: "Teams wanting to give a coding agent Gemini's media and research tools without adding an SDK. Pin a release in CI, since breaking changes can arrive between minor versions."
    sourceUrl: "https://ai.google.dev/gemini-api/docs/cli"
    sourceLabel: "Gemini API CLI guide"
  - vendor: "OpenAI"
    title: "Codex CLI 0.165.0"
    releasedOn: "27 Oct 2026, 20:09 UK"
    body: |
      Codex CLI now has a built-in Google Cloud Vertex AI provider (`model_provider = "gcp"`), GPT-6.1 Terra in its model catalogue, and mid-conversation reasoning effort changes switched on by default.

      Memory v2 is on by default for fresh profiles and can import memories from other agents, and the session picker gets a repository filter for working across linked worktrees.

      Fixes include not retrying when a provider says a model doesn't exist, and queued messages no longer restarting work after an interrupt.
    whoItAffects: "Organisations whose models are hosted on Vertex AI, which can now point Codex at them without a proxy."
    sourceUrl: "https://developers.openai.com/codex/changelog/"
    sourceLabel: "Codex changelog"
  - vendor: "Anthropic"
    title: "Claude Code 2.1.312"
    releasedOn: "27 Oct 2026, 20:23 UK"
    body: |
      The Claude apps gateway gets `oidc.user_id_claim`, so you can identify people by a claim other than `sub`, such as Entra ID's `oid`. Claude Code will no longer overwrite a very large CLAUDE.md or rules file after only reading its start.

      On Bedrock, Vertex, Foundry and Mantle, custom deployment names and inference profile ARNs now get the shorter system prompt (`CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0` keeps the full one).

      Hooks now run at most 24 at a time per session, the `claude_code.safety_event` OpenTelemetry event added last week has been dropped, and Code Review now reviews the PR's current commit when GitHub delivers a push event late.
    whoItAffects: "Anyone running Claude Code through Bedrock or Vertex with custom deployment names should check behaviour after upgrading, as the prompt change is silent. Dashboards built on the `claude_code.safety_event` event will stop receiving data."
    sourceUrl: "https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md"
    sourceLabel: "Claude Code changelog"
  - vendor: "SpaceAI"
    title: "Grok Bot 0.77.0"
    releasedOn: "26 Oct 2026"
    body: |
      1Password now connects without a shared vault: you approve each login in 1Password and it fills the Bot's browser without the Bot seeing the password.

      Settings gets a Permissions section listing Auto-review rules, approval cards stay open for 30 minutes instead of 10, and the Vault has a Payments tab for picking which payment method Bots use first.

      Bots can also ask several questions on one card, and custom MCP servers behind a private certificate authority work once you approve that authority.
    whoItAffects: "Teams connecting agents to internal systems, who can now use 1Password logins and MCP servers behind a private certificate authority without handing over secrets."
    sourceUrl: "https://x.ai/changelog/bot"
    sourceLabel: "Grok Bot changelog"
