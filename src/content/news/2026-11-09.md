  - vendor: "Anthropic"
    title: "Claude Code 2.1.319"
    releasedOn: "6 Nov 2026, 17:04 UK"
    body: |
      Auto mode behind an LLM gateway, or with telemetry or feature flags off, now asks or denies for calls the server can't check, instead of falling back to the built-in classifier. Setting `CLAUDE_CODE_AUTO_MODE_SERVER=0` keeps the old behaviour. `claude -p` now exits 1 when auto mode refuses actions for lack of a safety check.

      The release also adds a `permissions.denyInsteadOfPrompting` setting, moves MCP tasks to the background, adds `CLAUDE_CODE_DISABLE_FEATURE_FLAGS`, and brings several Claude apps gateway additions: pooled budget conflict rules, JSON logs, a login notice and spend in `/usage`.

      Fixes include Bash deny and ask rules missing commands with quoted words.
    whoItAffects: "Anyone running Claude Code through a gateway or in CI. Check your auto mode setup before upgrading, as the exit code and fallback behaviour have changed."
    sourceUrl: "https://github.com/anthropics/claude-code/releases/tag/v2.1.319"
    sourceLabel: "Claude Code 2.1.319 release"
  - vendor: "Cursor"
    title: "Voice Chat with Agents"
    releasedOn: "6 Nov 2026"
    body: |
      Realtime voice calls with agents are available in the Agents Window, IDE, web and iOS, including "Hey Siri, call Cursor". You can keep talking while the agent works, and the agent gives short spoken progress notes.

      It runs on Grok Voice, and with Privacy Mode on it runs with zero data retention. It is separate from dictation.
    whoItAffects: "Cursor users considering voice for work, who should check the zero data retention behaviour under Privacy Mode."
    sourceUrl: "https://cursor.com/changelog"
    sourceLabel: "Cursor changelog"
  - vendor: "Google"
    title: "Gemini API: gemini-embedding-2-preview deprecated"
    releasedOn: "6 Nov 2026"
    body: |
      `gemini-embedding-2-preview` is deprecated. Requests now route to `gemini-embedding-2` with the same schema, pricing and embedding space.
    whoItAffects: "Developers using the preview embedding model. No re-indexing is needed, but change the model string so you're not relying on the alias."
    sourceUrl: "https://ai.google.dev/gemini-api/docs/changelog"
    sourceLabel: "Gemini API changelog"
