    title: "Claude Code 2.1.316"
    releasedOn: "31 Oct 2026, 01:01 UK"
    body: |
      `CLAUDE_CODE_SUBAGENT_EFFORT` sets the effort level subagents run at instead of inheriting the session's, and `CLAUDE_CODE_DISABLE_ULTRATHINK` turns the `ultrathink` keyword off.

      The Claude apps gateway gets pooled group budgets (one shared monthly budget per group via `pooled_budget`), `managed.policy_mode: layered` so every matching policy applies rather than just the first, and `guardrail.input_tagging` for Bedrock guardrail prompt-attack filters. It also now checks every model a request names against the allow and deny lists, and returns a 400 naming the field.

      Fixes cover shell commands left running after Claude Code exits on its own, `--restricted` sessions uploading files from outside the working directories, Bash scripts stopping after one command when `SHELLOPTS` is exported, and Grep and Glob hanging on Windows. Server-managed settings for Team and Enterprise now apply without an approval prompt, and cloud sessions get a form card for MCP server requests.
    whoItAffects: "Teams running multi-agent work in Claude Code, who can now set subagent effort separately to manage cost, and platform teams running the Claude apps gateway, who should check how shared budgets, layered policies and the stricter model checks fit their setup."
    sourceUrl: "https://github.com/anthropics/claude-code/releases/tag/v2.1.316"
    sourceLabel: "Claude Code 2.1.316 release"

    title: "Claude Opus 4.8 fast mode deprecated"
    releasedOn: "30 Oct 2026"
    body: |
      Fast mode on `claude-opus-4-8` is removed on 30 November 2026. After that, `speed: "fast"` requests on Opus 4.8 return an error and don't fall back to standard speed. To keep the speedup you'll need to move to Opus 5.5.
    whoItAffects: "Anyone with requests pinned to Opus 4.8 fast mode. These will start failing rather than slowing down after 30 November 2026, so check configs for `speed: \"fast\"` on Opus 4.8 now."
    sourceUrl: "https://docs.claude.com/en/release-notes/overview"
    sourceLabel: "Claude release notes"

    title: "Gemini API Computer Use is generally available"
    releasedOn: "30 Oct 2026"
    body: |
      The Computer Use tool is now generally available on both the Interactions and GenerateContent APIs. It works with Gemini 4 Argon, Gemini 3.8 Flash (Google's recommended model for it) and Gemini 3.5 Flash-Lite.

      It includes configurable safety policies (for example, it won't accept terms of service on its own) plus prompt-injection detection.
    whoItAffects: "Developers building browser and UI automation on Gemini, who now have a generally available API and a Flash-Lite option alongside Argon."
