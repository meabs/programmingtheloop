    title: "GPT-6.1 Terra"
    releasedOn: "26 Oct 2026"
    body: |
      OpenAI's new fast, cheaper model is aimed at computer use, visual reasoning and writing. It's live in ChatGPT Work and Codex for Plus, Pro, Enterprise and Edu.

      In the API it's `gpt-6.1-terra`, with a 1.05M-token context window, reasoning effort from `none` to `max`, and tool calling through the Responses API only.

      OpenAI says standard API prices are half those of GPT-5.6 Terra and GPT-6.1 Sol ($1 per million input tokens), and that it scores 50.3% on Terminal-Bench 4.0 at max effort, more than double GPT-5.6 Terra. OpenAI still points people to GPT-6.1 Sol or GPT-6 Astra for the hardest coding work.
    whoItAffects: "Teams running high-volume screen and form automation, such as invoice entry. It's worth re-running the cost figures for any computer-use agent you've put on hold."

  - vendor: "Cursor"
    title: "Cursor Agent SDK, generally available"
    releasedOn: "20 Oct 2026"
    body: |
      You define an agent as a folder (`instructions.md`, a `tools/` folder of typed actions, skills, MCP connections and channels), run it locally with a playground, test it with `agent-sdk eval`, and deploy it to Cursor or your own infrastructure.

      Agents can wake on GitHub, GitLab and Bitbucket PR, comment and CI events, Slack mentions and DMs, webhooks, or a cron schedule. `agent-sdk github replay` turns a real PR into test payloads.
    whoItAffects: "Teams building review bots and triagers, which can now be versioned and tested in CI as ordinary code rather than kept as prompts in a dashboard."
    sourceUrl: "https://cursor.com/changelog"
    sourceLabel: "Cursor changelog"
  - vendor: "Anthropic"
    title: "Claude Code 2.1.311"
    releasedOn: "26 Oct 2026, 21:51 UK"
    body: |
      Standard-context sessions that went past 200K tokens no longer stop with "Usage credits required for 1M context". Claude Code now compacts and carries on.

      Subagents can use MCP tools from servers that finish connecting after they start, and Claude Code no longer retries requests the API has marked as not retryable, which could hang unattended runs.

      The self-hosted runner gets `--hold-idle-file` and `--max-hold-min` to keep an idle session alive while your host reports leftover processes.
    whoItAffects: "Anyone running long Claude Code sessions or unattended runners. These are mostly reliability fixes for the cases where a hung turn costs the most."
    sourceUrl: "https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md"
    sourceLabel: "Claude Code changelog"

    title: "Gemini API stores requests by default for new paid-tier projects"

    body: |
