  - vendor: "Anthropic"
    title: "Claude Code 2.1.314"
    releasedOn: "30 Oct 2026, 01:06 UK"
    body: |
      A new `permissions.blockWritesOutsideWorkingDirectories` setting makes Write, Edit and NotebookEdit refuse any path outside your working directories, in every permission mode.

      Gateway upstreams for Claude apps get an optional `groups` list for routing by IdP group, Bedrock gateway upstreams get `guardrail_trace`, and VS Code and the Desktop Code tab now compact idle conversations over 200K tokens.

      Fixes cover an "Invalid effort level" loop when an admin caps effort (it now lowers effort and retries), `claude -p` exiting 0 with no output after a failed startup (it now exits 1), gateways that reject tool_reference or beta headers (now retried without them), dotted model IDs like `claude-opus-4.8` being misread behind gateways, and sandbox protections not applying to worktrees under `-p --resume`. Version 2.1.313 is folded into this release.
    whoItAffects: "Anyone running Claude Code unattended or in CI. The write setting is worth turning on there, and scripts that call `claude -p` should check they now handle the non-zero exit when startup fails."
    sourceUrl: "https://github.com/anthropics/claude-code/releases/tag/v2.1.314"
    sourceLabel: "Claude Code 2.1.314 release"

    title: "Claude Platform Usage and Cost Analytics API, beta"
    releasedOn: "29 Oct 2026"
    body: |
      New `/v1/organizations/analytics/usage` and `/cost` endpoints, behind the beta header `analytics-usage-cost-2026-08-24`, are available to Console and Enterprise organisations. They support filtering and grouping by model, workspace, API key, and user or service account.

      The older Usage and Cost API and the Enterprise usage and cost report endpoints are now legacy but still supported.
    whoItAffects: "Teams that charge AI costs back to projects or need to spot a runaway agent by key or user. Anyone on the older endpoints should note they are now legacy."
