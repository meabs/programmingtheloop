    body: |
      The Claude apps gateway can now use `assume_role` on `mantle` upstreams, which gives cross-account AWS access and lets you attribute costs to each developer. Mods can set `effort` on `$.model.fork`, so a side job can run at `low` even when the session runs higher.

      Stored claude.ai sign-ins now show when they expire (`loginExpiresAt` and `credential_expires_at`), and `claude -p` prints a one-line warning to stderr starting 10 days before expiry. Cloud sessions can now start without a repository.

      Fixes cover `--continue` after retries of malformed tool calls, Bash stalls on macOS, race conditions on key presses at permission prompts, and config and MCP writes on network home folders. Remote Control and self-hosted runners no longer fail with `spawn ENOENT` after old versions are cleaned up.

      Behaviour changes: Claude Code no longer installs the IDE extension automatically from an IDE terminal, background subagents park long shell work after three minutes, and URL entries in `deniedMcpServers` now also block matching Anthropic connector upstreams.
